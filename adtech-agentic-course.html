Module 1

The Problem: Why Advertising Needs Agents

📅 Last updated: 2026-05-05 Baseline

📌 Overview

Before understanding AdCP or ARTF, you need to understand the broken world they're trying to fix. This module sets the stage for why agentic advertising protocols matter.

⚠️ The Core Problem

Digital advertising runs on hundreds of disconnected platforms. A media buyer at an agency must log into a DSP, an SSP, a DMP, a measurement tool, a curation platform — each with its own interface, API format, and opaque pricing. Budgets leak into intermediary layers. No single agent can 'see' the whole picture.

🔄 What Programmatic Looks Like Today

OpenRTB (open real-time bidding) is the backbone — a standard for auctioning individual ad impressions in under 100ms. It works, but it was designed for machines following deterministic rules, not AI agents reasoning in natural language about campaign goals.

📖 Key Concepts

TermDefinition
DSPDemand-Side Platform. Where advertisers/agencies buy ad inventory automatically.
SSPSupply-Side Platform. Where publishers sell ad inventory programmatically.
OpenRTBThe existing standard for real-time impression auctions. Works in <100ms per bid.
AI AgentAn autonomous AI that can reason, plan multi-step tasks, and take actions without human input per step.

💡 Why 'Agentic' Matters Now

AI agents can reason about campaign briefs in natural language ("find women interested in ultramarathons on premium news sites"), discover inventory, negotiate deals, and optimise — all without a human clicking through dashboards. But for agents to work together across platforms, they need shared protocols.

👤 Future Role Impact

Media PlannerYour role shifts from manually building plans to briefing an AI agent in natural language. The agent does the discovery and packaging.
Ad OpsInstead of managing platform UIs, you will manage agents — setting rules, auditing logs, and handling exceptions that agents escalate.
Ad Tech EngineerBuilding MCP-compatible services and agent APIs becomes core work. OpenRTB knowledge remains essential as a foundation.

AdCP: Ad Context Protocol Explained

📅 Last updated: 2026-05-05 Baseline

📌 Overview

Launched October 15, 2025 by 20+ companies including Yahoo, PubMatic, Scope3. Built on Anthropic's Model Context Protocol (MCP). This module covers what AdCP actually does, its four core modules, and its current adoption reality.

🔍 What is AdCP?

Ad Context Protocol (AdCP) is an open standard that gives AI agents a shared language to communicate with ad platforms — and eventually with each other. Think of it as "OpenRTB for agents": just as OpenRTB standardised how machines bid on impressions, AdCP standardises how agents brief, discover, negotiate, and buy.

Launch dateOctober 15, 2025
Founding membersYahoo, Optable, PubMatic, Scope3, Swivel, Triton Digital
Launch membersMagnite, Kargo, LG Ad Solutions, Raptive, Samba TV, The Weather Company + others (20+ total)
GovernanceNeutral working group — not owned by any single vendor

⚙️ AdCP's Four Core Modules

ModuleStatusPurpose
Signals Activation ProtocolAvailableDiscover, activate and manage audience data via natural language. Supports geographic, identity, and temporal signals.
Media Buy ProtocolAvailableEnd-to-end campaign execution — verify publisher auth, modify budgets, adjust targeting, handle approvals.
Creative ProtocolAvailableBuild ad creatives, preview formats, explain rendering. Agents can generate and check creative assets.
Curation ProtocolQ2 2026Standardise how inventory gets packaged and curated.

🔗 Built on Anthropic's MCP

AdCP is layered on top of the Model Context Protocol (MCP) — the same protocol Claude uses to connect to tools. Any AI assistant that supports MCP can, in theory, access advertising platforms directly through AdCP without custom integrations.

Key Distinction from OpenRTB
OpenRTB handles sub-100ms impression auctions. AdCP operates asynchronously — a media buy negotiation might take minutes, hours, or require a human sign-off. They are designed for different layers of the stack and are complementary.

📊 Adoption Reality (as of May 2026)

AdCP remains largely experimental. No major AI assistant platforms have integrated it. The chicken-and-egg problem: publishers build AdCP agents, but there are few AI buyers connecting to them yet. Early sell-side transactions via Swivel reported in late 2025.

👤 Future Role Impact

Media BuyerAdCP means your AI assistant could query "find $50K of premium running content inventory in APAC" and get structured responses from all compatible SSPs at once.
Publisher / SSPYou build an AdCP-compatible "seller agent" that responds to natural language inventory requests. Your packaging becomes automated and accessible to AI buyers.
Data / Audience StrategistThe Signals Activation Protocol means audience segments become discoverable via natural language — agents can find and activate them without manual setup.

ARTF: Agentic RTB Framework Explained

📅 Last updated: 2026-05-05 Baseline

📌 Overview

Released November 13, 2025 by IAB Tech Lab. Built on OpenRTB. Uses containerisation to cut latency by up to 90%. A fundamentally different approach to AdCP — operating at the impression level inside real-time bidding pipelines.

Release dateNovember 13, 2025 (public comment closed January 15, 2026)
Governing bodyIAB Tech Lab
Reference implementationGo (open-source on GitHub, credited to Index Exchange Inc.)
Built onOpenRTB — extends existing standards, does not replace them

📦 The Containerisation Breakthrough

ConceptExplanation
What is a container?Like a shipping container for software — packages all code and dependencies together. Runs inside one server instead of talking to others over the network.
Latency reductionARTF claims up to 80–90% latency reduction by running agent logic inside the same server as the bid.
Segment activationAgents can activate user segments based on bid request data in real time (e.g. user born 1990 viewing a sports site).
Backward compatibleExtends existing OpenRTB standards. Existing plumbing still works.

🏗️ Technical Architecture

ARTF exposes an RTBExtensionPoint service via gRPC. Agents receive an OpenRTB bid request and return proposed mutations:

Deal activations Bid price adjustments (bid shading) Segment additions Viewability metric additions

Also supports MCP and Agent-to-Agent (A2A) protocols. A Web UI is available for local testing.

⚖️ ARTF vs AdCP — Key Differences

DimensionARTFAdCP
LayerImpression-level, inside RTB pipelineDeal/campaign-level, between agents
SpeedReal-time (<100ms)Asynchronous (seconds to days)
FoundationOpenRTB (extends existing)MCP (native to agents)
ScopeExecution infrastructureCommunication language
RelationshipComplementary — both now under AAMP umbrella
Index Exchange Involvement
Joshua Prismon, Chief Architect at Index Exchange, was quoted in the ARTF v1.0 press release. The Go reference implementation on GitHub is credited to Index Exchange Inc. IX has direct involvement in shaping this standard.

👤 Future Role Impact

SSP / Exchange EngineerYou can expose ARTF-compatible agent extension points in your bidder. Third-party agents can enhance bids in real time without expensive integrations.
Yield Manager / Revenue OpsARTF enables per-impression sell-side decisioning at scale — AI can dynamically adjust floor prices, activate deals, and apply curation logic in real time.
Brand Safety / Fraud AnalystAgent logic for brand safety checks can run inside the bid pipeline itself — faster responses, no external API calls per impression.

AAMP: The Big Picture

📅 Last updated: 2026-05-05 Baseline

📌 What is AAMP?

Agentic Advertising Management Protocols (AAMP) is the umbrella initiative announced February 26, 2026. It unifies all of IAB Tech Lab's agentic work under one coordinated roadmap. Think of it as the full "operating system" for agentic advertising.

AnnouncedFebruary 26, 2026 (Beet.TV Beet Retreat event)
Governing bodyIAB Tech Lab
FramingResolves market confusion by naming the full initiative — ARTF and Agentic Audiences are components, not the sum total

🏛️ The Three Pillars of AAMP

Pillar 1
High-Performance Delivery
ARTF lives here. Containerised infrastructure for agents inside real-time bidding at scale. Up to 90% latency reduction. The foundation for agents operating at machine speed.
Pillar 2
Shared Protocols
Seven agentic protocol components, each mapped to an existing IAB Tech Lab standard: Audiences, Ad Objects, Direct, Deals, RTB, Mobile, Measurement.
Pillar 3
Trust & Transparency
The Agent Registry — a public database of verified agents. Any agent transacting in the ecosystem must be registered. Launched March 1, 2026.

📋 The Seven Protocol Components

ProtocolBased onPurpose
Agentic Audiences (UCP)User Context Protocol (LiveRamp donation)Embedding-based audience signal exchange between agents
Agentic Ad ObjectsAdCOMStandardised ad object definitions across contexts
Agentic DirectOpenDirectAgents negotiate and transact direct deals without human intervention per step
Agentic DealsDeals APIAgent-driven deal negotiation and activation
Agentic RTBOpenRTBARTF integration — agents inside the bid stream
Agentic MobileCloudX donationAgentic workflows in mobile app ecosystem
Agentic MeasurementOM SDK / Conversion APIMeasurement signals for agentic transactions

🧬 Agentic Audiences (formerly UCP)

Donated by LiveRamp November 3, 2025. Standardises how agents exchange identity signals, contextual signals, and performance data using dense vector embeddings (256–1024 dimensions). How a buyer agent tells a seller agent "I need audiences like X" in a privacy-preserving, machine-readable format. Aligned with TCF and GPP privacy frameworks.

Agent Registry
Every agent operating in the AAMP ecosystem must be registered — who built it, what version, what protocols it supports, who is accountable. Launched March 1, 2026. Directly addresses fraud and accountability risks of autonomous agents spending real money.

🗓️ 2026 Roadmap Commitments

✓
Open-source reference implementations of buyer and seller agents (released)
→
Neutral MCP reference server
→
Standardised agent profiles
→
Protocol Buffers and gRPC mappings for existing specifications
→
Trust, provenance, and measurement signals for transaction integrity

👤 Future Role Impact

Ad Tech Platform (DSP/SSP)Clear integration roadmap: implement Buyer Agent SDK (demand side) or Seller Agent SDK (supply side) from IAB Tech Lab's GitHub. Register your agents with the registry.
Privacy / LegalAgentic Audiences uses embeddings aligned with TCF and GPP. Compliance requirements are encoded into the protocol layer, not bolted on.
Ad Standards LeadAAMP extends AdCOM, OpenDirect, and Deals API — existing standards you know. The agentic layer is additive, not a full replacement.

AdCP vs AAMP/ARTF: The Standards Battle

📅 Last updated: 2026-05-05 Baseline

📜 The Origin Story

When AdCP launched in October 2025, IAB Tech Lab CEO Anthony Katsur publicly questioned whether the industry needed "another industry trade group." Six weeks later, IAB Tech Lab released ARTF. Then in February 2026, AAMP was unveiled. IAB Tech Lab's framing: AAMP is not a reaction to AdCP — it's months of pre-existing work. The timing tells a story regardless.

⚖️ Key Differences at a Glance

DimensionAdCPAAMP / IAB Tech Lab
GovernanceNeutral working group, 20+ companies, not vendor-ownedIAB Tech Lab — established non-profit since 2014, proven governance
Technical approachNative-to-agents, built on MCP, asynchronous, natural language firstExtends proven standards (OpenRTB, AdCOM, OpenDirect), containerised real-time execution
ScopeDeal-level agent communication and transactionFull stack: infrastructure + protocols + governance
FoundationAnthropic's MCPOpenRTB, AdCOM, OpenDirect, Deals API
Adoption (May 2026)Early sell-side transactions via Swivel; no major AI assistant integrationBuyer/Seller SDKs released; Agent Registry live; ARTF v1.0 finalised
Fragmentation Risk
If SSPs implement AdCP and DSPs implement AAMP protocols without interoperability, every agent needs custom integration per platform — recreating exactly the fragmentation both protocols are trying to solve. IAB Australia and others are explicitly calling for convergence.

🤝 The Emerging Consensus (May 2026)

The industry increasingly views these as complementary layers:

AAMP / ARTF
Execution Infrastructure
High-performance impression-level, real-time bidding. The pipes.
AdCP
Deal-Level Language
Asynchronous campaign-level agent negotiation. The conversation.
